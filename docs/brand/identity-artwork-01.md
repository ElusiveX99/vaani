# Vaani identity — proposed final artwork package

**Design status: final artwork candidate uploaded for review. Not merged into the live application.**

## Identity concept

The wordmark is drawn as a custom monoline lettering system rather than set in a font. Its visual language is built around three linked ideas:

- The V's descent and lifted exit establish the word's opening gesture.
- The repeated single-storey a forms create a measured cadence rather than a decorative underline.
- The open bowl and rising shoulder become the source for the square derivative.

The square derivative uses that open-bowl/rising-shoulder gesture, not an unrelated generic V. Its silhouette is intentionally simple and contained for small-scale use.

## Strict limitations and release gates

This package is uploaded as a final-artwork candidate, not falsely certified as having passed every identity test. The vector construction is custom and font-independent, but the following still require rendered QA in the actual application and physical output: 16 px favicon recognition, 32 px app icon, optical balance at actual header sizes, social avatar crop, embroidery, one-color print, accessibility contrast in every use, and competitive distinctiveness review.

The 50-point identity rubric remains the acceptance standard. A gate is not considered passed merely because an SVG file exists. In particular, small-size legibility, symbol independence, distinctiveness, and cultural respect need real review evidence.

No application references, metadata, PWA assets, social preview images, or deployment have been changed in this upload. Do not merge or deploy this package until the rendered tests and final approval are complete.
