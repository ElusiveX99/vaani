# Vaani identity assets

The identity uses an original, hand-authored floral emblem with an organic five-petal silhouette. Its form is intentionally simple enough to remain legible at small sizes.

## Core palette
- Deep plum: `#593B53`
- Muted rose: `#AD7D83`
- Warm ivory: `#FFFDF9`
- Soft petal: `#E7D4D0`
- Antique gold accent: `#C5A07D`

## Files
- `vaani-lockup.svg`: primary horizontal emblem + wordmark.
- `vaani-emblem.svg`: primary standalone emblem for light surfaces.
- `vaani-emblem-light.svg`: reversed emblem for dark surfaces.
- `vaani-emblem-monochrome.svg`: single-color emblem.
- `vaani-wordmark.svg`: standalone wordmark.
- `favicon.svg`: compact square favicon artwork.
- Browser/app PNG icons are generated from the same emblem by Next.js metadata routes at `/icon` and `/apple-icon`.

The site wordmark remains live text in the interface so it uses Vaani's loaded Cormorant Garamond font and stays crisp at every display scale. The standalone SVG wordmark uses a serif fallback for portability.
